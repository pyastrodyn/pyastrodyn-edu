# Validation problems

Worked problems that can be reproduced by hand or with the library. The
statements and the numbers were written for this library and are not taken
from a book; each problem names the book whose worked examples inspired it.
The given data are exact as printed;
results are given with seven significant digits, except those of numerical
integrations, which are given with as many digits as are reproducible.
Units: km, s, kg; angles in degrees.

This file is generated by `tools/make_docs.py` from
`pyastrodyn_edu/validation.py`. Do not edit it by hand.

To solve a problem with the library:

```python
from pyastrodyn_edu import validation
problem = validation.get("L4-1")
print(problem.results())
```

Every problem is also worked out step by step as an **example problem**,
in two forms with the same content: a notebook, to experiment, and a
script, to read. They are in the folders `examples/lectureNN`; the files
of each problem are named under it below. Problem L4-1 is Example
problem 4.1, and so on. How to use them: Step 11 of
`docs/getting_started.md`.
