# Validation problems

Worked problems that can be reproduced by hand or with the library. The
statements and the numbers were written for this library and are not taken
from a book; each problem names the book whose worked examples inspired it.
The given data are exact as printed;
results are given with seven significant digits, except those of numerical
integrations, which are given with as many digits as are reproducible.
Units: km, s, kg; angles in degrees.

This file is generated by `tools/make_docs.py` from
`pyastrodyn_edu/validation.py`. Do not edit it by hand.

To solve a problem with the library:

```python
from pyastrodyn_edu import validation
problem = validation.get("L4-1")
print(problem.results())
```

Every problem is also worked out step by step as an **example problem**,
in two forms with the same content: a notebook, to experiment, and a
script, to read. They are in the folders `examples/lectureNN`; the files
of each problem are named under it below. Problem L4-1 is Example
problem 4.1, and so on. How to use them: Step 11 of
`docs/getting_started.md`.

### L1-3. Step size and accuracy of a fixed-step integration

Starting from the state of problem L1-1, integrate the equation of motion over exactly one orbital period with the Runge-Kutta method of order 4, first with 200 equal steps and then with 400. After one period the spacecraft must be back at its starting point, so the distance between the final and the initial position is the error. Find the period, the two errors and their ratio.

**Given**

|---|---|---|

| `steps_coarse` | 200 | - |
| `steps_fine` | 400 | - |

**Results**

| Quantity | Value | Unit |
|---|---|---|
| `period` | 6198 | s |
| `error_coarse` | 0.001323 | km |
| `error_fine` | 7.4446e-05 | km |

**Worked out in** `examples/lecture01/example_1_3_rk4_step_size.ipynb` (notebook) and `examples/lecture01/example_1_3_rk4_step_size.py` (script).

**Independent check.** For a method of order 4 the ratio must be close to 2^4 = 16; halving the step once more must divide the error by about 16 again; and the error measured against the solution of Kepler's equation must agree.

*Inspired by the worked examples in Vallado, *Fundamentals of Astrodynamics and Applications*. The statement and the numbers were written for this library.*

### L1-4. Tolerance and accuracy of an adaptive integration

| `revolutions` | 10 | - |
| `rtol_loose` | 1e-06 | - |
| `rtol_medium` | 1e-09 | - |
| `rtol_tight` | 1e-11 | - |

**Results**

| Quantity | Value | Unit |
|---|---|---|
| `error_loose` | 2.5 | km |
| `error_medium` | 0.00037 | km |
| `error_tight` | 1.6e-06 | km |

**Worked out in** `examples/lecture01/example_1_4_integration_tolerance.ipynb` (notebook) and `examples/lecture01/example_1_4_integration_tolerance.py` (script).

**Independent check.** The error must fall as the tolerance is tightened; the drift of the specific energy must fall in the same order; and the error measured against the solution of Kepler's equation must agree.
